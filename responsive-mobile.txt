======================================================
  CONDUITE 2000 — Documentation Responsive Mobile
  Fichier source : styles.css
======================================================

Ce fichier liste toutes les règles CSS qui rendent le site
adapté aux écrans mobiles (smartphones et petites tablettes).
Chaque bloc @media explique CE qui change et POURQUOI.


------------------------------------------------------
1. NAVIGATION (breakpoints : 880px et 480px)
------------------------------------------------------

@media (max-width: 880px) {
  .nav-links { display: none; }     /* Cache les liens de nav (À propos, Agences…) */
  .nav-cta   { display: none; }     /* Cache le bouton "06 19 02 28 32" */
  .nav-burger { display: flex; }    /* Affiche le bouton hamburger ☰ */
}

  → En dessous de 880px, la barre de navigation horizontale
    disparaît et est remplacée par un bouton hamburger.
    Le menu mobile (.nav-mobile-menu) s'ouvre en cliquant dessus.

@media (max-width: 480px) {
  .nav-inner { padding: 8px 8px 8px 14px; gap: 10px; }
  .nav-brand span { display: none; }    /* Cache "Depuis 1984" sous le logo */
  .nav-brand b { font-size: 16px; }     /* Réduit la taille du nom de marque */
  .nav-mobile-menu { top: 72px; }       /* Ajuste la position du menu déroulant */
}

  → Optimisations supplémentaires pour les très petits écrans (iPhone SE…).


------------------------------------------------------
2. HERO — Section principale (breakpoints : 940px, 640px, 420px)
------------------------------------------------------

@media (max-width: 940px) {
  .hero-grid { grid-template-columns: 1fr; gap: 40px; }
  /* Le grid passe de 2 colonnes (texte | scène 3D) à 1 colonne */

  .hero-visual {
    width: min(420px, 90vw);
    margin: 0 auto;
    transform: translateZ(0);
  }
  /* La scène isométrique passe en dessous du texte, centrée */

  .scene { transform: rotateX(55deg) rotateZ(-35deg) scale(.9); }
  /* Légèrement réduite pour tenir dans la colonne */
}

@media (max-width: 640px) {
  .hero { padding-top: 100px; padding-bottom: 48px; }
  .hero h1 { font-size: clamp(40px, 11vw, 68px); }   /* Titre plus petit */
  .hero-lede { font-size: 16px; }                      /* Sous-titre plus petit */
  .hero-stats { gap: 20px; margin-top: 36px; }
  .hero-stats div b { font-size: 28px; }               /* Chiffres (40+, 2, 1€) réduits */
  .hero-tag { display: none; }                          /* Cache le badge "EST. 1984" */
  .hero-visual { width: min(300px, 84vw); aspect-ratio: 1/1; }
  .scene { transform: rotateX(55deg) rotateZ(-35deg) scale(.74); }
  /* Cartes flottantes (Permis B, Permis 1€) simplifiées : */
  .hero-card { padding: 9px 12px; gap: 8px; border-radius: 12px; }
  .hero-card b { font-size: 12px; }
  .hero-card span { display: none; }   /* Cache le sous-titre des cartes */
  .hero-card .icon { width: 30px; height: 30px; font-size: 12px; }
}

@media (max-width: 420px) {
  .hero-visual { display: none; }      /* Cache complètement la scène 3D */
  .hero { padding-top: 90px; }
  .hero h1 { font-size: clamp(36px, 12vw, 54px); }
  .hero-tag { display: none; }
}

  → Sur mobile, la mise en page 2 colonnes (texte + scène 3D)
    devient une colonne unique. La scène disparaît sur très petit écran
    pour libérer de l'espace pour le contenu essentiel.


------------------------------------------------------
3. SECTION "À PROPOS" — Bento grid (breakpoint : 940px)
------------------------------------------------------

@media (max-width: 940px) {
  .about-bento { grid-template-columns: repeat(6, 1fr); }
  .bento.lead, .bento.value, .bento.team,
  .bento.partner, .bento.cta { grid-column: span 6; }
}

  → Le bento grid (layout mosaïque) passe de 12 colonnes à 6,
    et chaque bloc occupe toute la largeur (span 6 = 100%).
    Les blocs s'empilent verticalement au lieu d'être côte à côte.


------------------------------------------------------
4. SECTION "AGENCES" (breakpoint : 840px)
------------------------------------------------------

@media (max-width: 840px) {
  .agencies-grid { grid-template-columns: 1fr; }  /* 2 colonnes → 1 colonne */
  .agency { padding: 28px; }                       /* Moins de padding */
  .agency .h-row { grid-template-columns: 12px 62px 1fr; gap: 8px; }
  .agency .h-row .day { font-size: 10px; letter-spacing: .10em; }
  .agency .agency-phone b { font-size: 18px; }    /* Numéro de téléphone plus petit */
}

  → Les deux cartes d'agences (Bourgbarré / Orgères) passent
    de côte à côte à empilées verticalement.


------------------------------------------------------
5. SECTION "FORMATIONS" (breakpoints : 940px et 600px)
------------------------------------------------------

@media (max-width: 940px) {
  .formations-grid { grid-template-columns: repeat(2, 1fr); }
  .f-1, .f-2, .f-3, .f-4, .f-5 { grid-column: span 2; }
  /* Le grid 12 colonnes passe à 2 colonnes égales */
}

@media (max-width: 600px) {
  .formations-grid { grid-template-columns: 1fr; }
  .f-1, .f-2, .f-3, .f-4, .f-5 { grid-column: span 1; }
  /* 1 seule colonne : les 5 formations s'empilent */
}

  → Sur tablette : 2 cartes par ligne.
    Sur mobile : 1 carte par ligne (pleine largeur).


------------------------------------------------------
6. SECTION "PERMIS 1€" (breakpoint : 840px)
------------------------------------------------------

@media (max-width: 840px) {
  .perm1 { padding: 40px 28px; }            /* Moins de padding */
  .perm1-grid { grid-template-columns: 1fr; gap: 40px; }
  /* Le grid 2 colonnes (texte | stats) passe à 1 colonne */
}

  → Le bloc "1€ par jour" s'adapte à une colonne unique.
    Le texte apparaît en premier, les statistiques en dessous.


------------------------------------------------------
7. SECTION "TARIFS" (breakpoint : 840px)
------------------------------------------------------

@media (max-width: 840px) {
  .tarifs-grid { grid-template-columns: 1fr; }
  /* Les 4 cartes de tarifs passent de 2 colonnes à 1 colonne */
}

  → Les cartes tarifaires s'empilent verticalement sur mobile.


------------------------------------------------------
8. SECTION "DOCUMENTS & LABEL" (breakpoint : 940px)
------------------------------------------------------

@media (max-width: 940px) {
  .docs-grid { grid-template-columns: 1fr; }      /* 2 colonnes → 1 colonne */
  .docs ul { grid-template-columns: 1fr; }         /* Liste docs en 1 colonne */
}

  → La liste de documents et le bloc "Label Qualité"
    s'empilent au lieu d'être côte à côte.


------------------------------------------------------
9. SECTION "CONTACT" (breakpoint : 940px)
------------------------------------------------------

@media (max-width: 940px) {
  .contact-grid { grid-template-columns: 1fr; }   /* 2 colonnes → 1 colonne */
  .form-grid { grid-template-columns: 1fr; }       /* Formulaire : 2 champs → 1 champ par ligne */
  .field.wide { grid-column: span 1; }             /* Les champs "wide" n'ont plus besoin de span */
}

  → Le formulaire et la colonne latérale (téléphone, réseaux) s'empilent.
    Le formulaire passe à une seule colonne de champs.


------------------------------------------------------
10. FOOTER (breakpoint : 840px)
------------------------------------------------------

@media (max-width: 840px) {
  .footer-grid { grid-template-columns: 1fr 1fr; }
  /* Le footer passe de 4 colonnes à 2 colonnes */
}

  → Sur mobile, les 4 colonnes du footer (Brand / Nav / Bourgbarré / Orgères)
    passent à 2 colonnes × 2 lignes.

======================================================
  COMPOSANT : MENU MOBILE (.nav-mobile-menu)
======================================================

Le menu hamburger est géré conjointement par CSS et JavaScript.

HTML :
  <button class="nav-burger" id="navBurger">   ← bouton ☰
  <div class="nav-mobile-menu" id="navMobileMenu">  ← panneau déroulant

CSS :
  .nav-mobile-menu { display: none; }          ← caché par défaut
  .nav-mobile-menu.open { display: block; }    ← visible quand JS ajoute .open
  .nav-burger.open span { ... }                ← animation ☰ → ✕

JS (script.js) :
  Le clic sur le bouton ajoute/retire la classe .open sur les deux éléments.
  Fermeture automatique quand on clique sur un lien du menu.
